Often, the data we wish to present are logically arranged in a sequence — an acquired movie during an in-situ TEM experiment, a frame-by-frame multislice simulation, or 360° orbits around 3D visualisations. In typical print journals these are presented as still snapshots or attached as supplemental material. Since the journal is meant to be read online, we can embed the playback directly on the page in several ways, from a fully-interactive in-browser widget down to a plain HTML5 video.

[](#fig_movie_anywidget) is a kernel-less movie player built as an [anywidget](https://anywidget.dev): play / pause, loop, bounce, scrubbable frame slider, plus the same display-range, colormap and zoom controls as the image widget on the previous page. The page loads instantly because no Python kernel is involved.

::::

The same playback can be driven by a Python kernel via JupyterLite. Two flavours are useful: a pre-baked HTML5 animation generated by matplotlib's `FuncAnimation` ([](#fig_movie_widget_ipympl)), and a fully-interactive player driven by ipympl + ipywidgets ([](#fig_movie_widget_ipympl_ipywidgets)). The animation is lightweight and replays on a fixed loop; the interactive version exposes the same scrub, contrast, and colormap controls as the anywidget version.
